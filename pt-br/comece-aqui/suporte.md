# Suporte

O suporte é feito por ticket no nosso Discord.

{% hint style="success" %}
[Abrir um ticket no Discord](https://discord.gg/sj3T9naGG2)
{% endhint %}

## Antes de abrir o ticket

{% stepper %}
{% step %}
### Confira os problemas comuns

Cada produto tem uma página de **Problemas comuns** com as soluções mais pedidas.
{% endstep %}

{% step %}
### Rode o diagnóstico

Entre no servidor com um personagem, abra o console do F8 e digite `onedebug`. Tire um print do resultado.
Ele mostra o framework detectado, seu personagem, dinheiro e grupos do jeito que nossos scripts enxergam.

[Saiba mais sobre o onedebug](../one-lib/diagnostico.md)
{% endstep %}

{% step %}
### Junte o que vamos pedir

* Print do `onedebug`.
* Print do erro (console do servidor e/ou F8), se houver.
* Framework e versão (ex.: QBCore atualizado em março).
* Passo a passo para o problema acontecer.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Tickets com essas informações costumam ser resolvidos na primeira resposta.
{% endhint %}
