# Base Network One

A Network One é a base onde nossos sistemas nascem e são testados todos os dias. Ela reúne todos os
produtos da Network Scripts já integrados entre si, com o mesmo padrão de interface, desempenho e segurança.

{% hint style="info" %}
**Em breve.** A base será lançada quando o pacote principal de sistemas estiver completo.
Acompanhe no [Discord](https://discord.gg/sj3T9naGG2).
{% endhint %}

## O que vem incluso

* Todos os produtos `one_*` lançados até a data da compra, já configurados.
* `one_lib` e integração completa entre os sistemas (ex.: a identidade criada no `one_characters` vira item no inventário).
* Design único em todas as telas.
* Estrutura de banco pronta e migrações automáticas.

## Para quem é

* Quem vai **abrir uma cidade nova** e quer começar com tudo integrado.
* Quem quer **migrar** de uma base antiga sem montar o quebra-cabeça de dezenas de scripts de autores diferentes.
